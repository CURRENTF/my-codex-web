## 当前稳定协议边界

`thread/read({ includeTurns: true })` 不保证持久恢复所有历史命令细节；V1 按 Plan 不启用实验 `thread/items/list`，也不复制 Codex Session 数据。因此 App Server 重启后，稳定响应未返回的旧命令输出不能无损重建。该限制不影响当前后端管理的实时 Turn、状态、Steer、Fork、Side Chat 或 Goal 闭环。
